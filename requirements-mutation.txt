# Install, in the environment that requirements-dev.txt made (its setuptools builds yattag):
#   python -m pip install --require-hashes -r requirements-dev.txt
#   python -m pip install --require-hashes --no-build-isolation -r requirements-mutation.txt
# --no-build-isolation: yattag 1.16.1, which Cosmic Ray needs for its HTML report, exists only as
# source (yattag-1.16.1.tar.gz, its hash PyPI's) with no build settings of its own, so pip would
# fetch an unpinned build tool for it; this way the pinned setuptools of requirements-dev.txt
# builds it. Its licence is LGPL, a developer tool that never ships. Every other file is a wheel,
# one hash for Windows (win_amd64) and one for Linux (manylinux x86_64) where they differ, both
# CPython 3.13, from the two download commands of requirements-dev.txt run with
#   cosmic-ray==8.9.0 --no-deps

#   toml -c <the name==version pins of requirements-dev.txt>
